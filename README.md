# R6 Intel

Rainbow Six Siege intel: every operator with loadouts and biographies, the map pool, the rank ladder and player stat lookup. Built with SvelteKit 2, Svelte 5 and Tailwind CSS 4, and prerendered as a static site.

## Development

Requires Node 20.19 or newer.

```bash
npm install
npm run dev
```

| Command         | What it does                                |
| --------------- | ------------------------------------------- |
| `npm run build` | Static build into `build/`                  |
| `npm run check` | Type-check with svelte-check                |
| `npm test`      | Unit tests (Vitest)                         |
| `npm run sync`  | Refresh operator data from ubisoft.com      |
| `npm run sync:maps` | Refresh map data from ubisoft.com       |

## Updating operators

Operator data lives in `src/lib/data/operators.json` and is generated by `scripts/sync-operators.mjs` from the official operator pages on ubisoft.com.

```bash
npm run sync            # data only
npm run sync -- --images  # also downloads new portraits, badges and loadout images as WebP
```

Existing images are skipped. Release seasons and squads aren't on ubisoft.com, so add them by hand in `src/lib/data/meta.ts` when a new operator launches. The build fails if an operator has no release season.
